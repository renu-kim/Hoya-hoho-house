## 제공하면 바로 반영 가능한 형식

아래 형식으로 정리하면 `stay-data.js`에 옮기기 쉽습니다. **출입 비밀번호는 보내거나 적지 않습니다.**

```text
[호야네]
주소:
네이버 지도 링크:
카카오맵 링크:
공개용 관리자 연락처 / 문의 시간:
입실 / 퇴실 시간:
입실 방법 (비밀번호 제외):
주차 가능 대수 / 위치 / 만차 시 확인된 대안:
숙소 구성과 비품:
주요 시설 사용법:
바비큐:
흡연 / 반려동물 / 인원 / 소음 규칙:
쓰레기·분리수거 / 퇴실 안내:
소화기 / 대피 경로 / 구급함:
주변 관광지 / 편의시설 / 지도 링크:
사진:

[호호네]
같은 항목으로 작성
```

## 숙박객 발송 전

- [ ] 각 숙소의 사실관계와 실제 위치를 운영자가 확인했습니다.
- [ ] 서로 다른 숙소의 주소·연락처·사진이 섞이지 않았습니다.
- [ ] `node tools/validate.cjs --production`을 통과했습니다. Node 미사용 시 동일 항목을 수동으로 확인했습니다.
- [ ] 초안용 `notice`를 수정 또는 삭제하고 `ready`, `updatedAt`을 갱신했습니다.
- [ ] PC·Android·iPhone·사용할 메신저 인앱 브라우저에서 길찾기·전화·문자·복사를 눌러 확인했습니다.
- [ ] `/hoya/`와 `/hoho/`를 각각 새 탭에서 열고 새로고침해도 올바른 숙소입니다.
- [ ] 사진 누락, 작은 화면 가로 넘침, 겹치는 하단 버튼이 없습니다.
- [ ] 공개 파일과 Git 이력에 비밀번호·예약자 정보·API 키·내부 주소가 없습니다.
- [ ] GitHub Pages의 사업/상거래 이용 정책에 대한 적합성을 확인했습니다.
- [ ] 배포 URL 메타데이터를 생성하고 실제 메신저 공유 결과를 확인했습니다.
- [ ] 운영 중 변경사항을 수정할 담당자와 확인 주기를 정했습니다.

사업 관련 주차·환불·화재 대피 등 실제 안내는 임의 추정하지 않습니다. 이 문서는 법률·시설 안전 적합성을 판정하는 문서가 아닙니다.
