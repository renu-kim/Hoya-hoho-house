## 환경과 검증 범위

Chromium에서 HTML/CSS/JavaScript를 메모리에 로드하여 화면 및 이벤트 동작을 검사했습니다. 이 작업 환경의 브라우저는 HTTP/file 직접 페이지 탐색을 허용하지 않아, URL·저장소·클립보드·공유 기능에는 명시적인 테스트 대역을 사용했습니다. 네트워크에 게시된 GitHub Pages를 실제 탐색한 E2E 검증이 아닙니다.

숙소별 링크는 생성 결과와 우선순위 로직을 검사했고, 한 파일 미리보기에서의 숙소 전환은 실제 클릭으로 검사했습니다. 테스트 주소·전화·주변 장소는 테스트 파일에서만 주입하며 운영 설정에는 포함되지 않습니다.

## 아직 확인하지 않은 항목

실제 GitHub 저장소 업로드·Pages 게시·HTTPS 인증·운영 도메인 접근은 수행하지 않았습니다. Android/iOS 및 카카오톡 인앱 브라우저의 네이티브 전화·문자·공유·지도 앱 실행은 실제 기기로 검사해야 합니다. 자동 복사 성공/실패 로직 검사는 실제 기기의 클립보드 권한 확인을 대체하지 않습니다.

주소·주차 가능 구역·입퇴실 규칙·소방시설·관광지·이동시간·사진 사용권의 사실 검증은 운영자의 정보가 없으므로 미수행입니다. 실제 사진 경로와 메신저 Open Graph 이미지 캐시도 운영자료 입력과 배포 후 확인이 필요합니다.

접근성은 키보드 탐색·모달 포커스·동작 줄이기 등의 기본 항목을 검사한 것이며, 스크린리더 전수검사나 WCAG 인증을 의미하지 않습니다. 호스팅 정책 적합성 확인도 별도로 필요합니다.

재실행: `python tools/test_browser.py --output test-output/results.json` (개발환경에 Python·Playwright·Chromium 필요). 사이트 실행·게시에는 테스트 도구가 필요하지 않습니다.
